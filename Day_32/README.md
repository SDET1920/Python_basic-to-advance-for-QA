Faker Data Generation in Python

A simple Python project demonstrating how to generate fake data using the Faker library.

This project shows three examples:

Generate fake data using Faker's default locale.

Generate fake data in the Indian format (en_IN).

Generate fake data in Hindi/Indian format (hi_IN).

📌 About Faker

Faker
 is a Python library that generates realistic-looking fake data for development, testing, and demonstration purposes.

You can generate data such as:

Names

Email addresses

Addresses

Phone numbers

Dates

Companies

Jobs

And much more

🚀 Installation

First, install the Faker package using pip:

pip install Faker

📂 Examples
Example 1 — Default Fake Data
from faker import Faker

fake = Faker()

print(fake.name())
print(fake.email())
print(fake.address())
print(fake.phone_number())


This uses Faker's default locale.

Example output may look like:

John Smith
john.smith@example.com
123 Main Street
New York, NY 10001
+1-555-123-4567


The generated values will be different each time you run the program.

Example 2 — Fake Data in Indian Format

To generate data based on the Indian locale, use en_IN:

from faker import Faker

fake = Faker("en_IN")

print(fake.name())
print(fake.email())
print(fake.address())
print(fake.phone_number())


en_IN represents the English (India) locale.

The generated data can include Indian names, addresses, phone numbers, and other localized information.

Example 3 — Fake Data in Hindi

To generate fake data using the Hindi (India) locale, use hi_IN:

from faker import Faker

fake = Faker("hi_IN")

print(fake.name())
print(fake.email())
print(fake.address())
print(fake.phone_number())


hi_IN represents the Hindi (India) locale.

This is useful when you want to generate test data containing Hindi-language names, addresses, and other localized values.

🌐 Faker Locales

Faker supports many different locales.

Some examples:

Locale	Language / Region
en_US	English (United States)
en_GB	English (United Kingdom)
en_IN	English (India)
hi_IN	Hindi (India)
fr_FR	French (France)
de_DE	German (Germany)
ja_JP	Japanese (Japan)

You can select a locale when creating the Faker object:

fake = Faker("hi_IN")
