#Operators in python-- A symbol which will perform an operation in between two or more variables.

1- Arithmetic
2- Comparison
3- Logical
4- Assignment
5- Membership

#Arithmetic Operators
1- Used for mathmatical operations

Operator	Meaning	  Example
+	  Addition	      a + b
-	  Subtraction	  a - b
*	  Multiplication  a * b
/	  Division	      a / b
%	  Modulus	      a % b
//	  Floor Division  a // b
**	  Exponent	      a ** b

#Comparison Operators

1- Used to compare values.

Operator	Meaning	      Example
==	      Equal to	      a == b
!=	    Not equal to	  a != b
>	   Greater than	      a > b
<	   Less than	       a < b
>=	  Greater than equal to	a >= b
<=	  Less than equal to	a <= b

#Logical Operators

1- Used to combine conditions.

Operator	Meaning
and	        Both conditions True
or	        Any one True
not	        Reverse result

#Assignment Operators
Operator	Example	 Meaning
=	       a = 5	    Assign value
+=	     a += 2	    Add and assign
-=	    a -= 2	  Subtract and assign
*=	    a *= 2	 Multiply and assign
/=	    a /= 2	 Divide and assign
%=	   a %= 2	 Modulus and assign
//=	   a //= 2	 Floor divide and assign
**=	   a **= 2	 Power and assign
