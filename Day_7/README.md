#Control statement.

1- Control statements determine the flow of execution in a program. 
2-They help the program make decisions, repeat actions, or change the normal sequence of execution.

A- Conditional statement- if, else, if-elif-else.

B- Looping statement- for, while

C- Jumping statement- break, continue.
