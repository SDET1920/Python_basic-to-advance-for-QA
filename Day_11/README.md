# Day 11: Python Collections

This lesson covers Python collections and how to use them in basic QA automation tasks.

## Topics included

- `list`: ordered, mutable, allows duplicate values
- `tuple`: ordered, immutable, allows duplicate values
- `set`: unordered, mutable, no duplicate values
- `dict`: key-value pairs, keys are unique
- `collections.Counter`: counts occurrences in an iterable
- `collections.defaultdict`: provides a default value for missing dictionary keys
- `collections.namedtuple`: lightweight object type with named fields

## File

- `collection.py` contains examples for each collection type.
