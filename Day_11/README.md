# Python List Operations

## Introduction

In Python, **List** is one of the collection data types.
Collection types are:

1. List
2. Tuple
3. Set
4. Dictionary

A **List** is:

* Ordered
* Mutable (changeable)
* Allows duplicate values
* Written inside square brackets `[]`

---

# Creating Lists

List can store:

* Numbers

* Mixed data types
