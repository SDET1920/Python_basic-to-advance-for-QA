#Looping statement-- if you have certain number of statement and if you want to print multiple time.
1- A looping statement in Python is used to execute a block of code repeatedly.

2- Python mainly provides two looping statements:

#range()-  Generates a sequence of numbers.

#range(10)     (0--10)

#range(1,10)   (1---9)

#range(1,10,2)   (1 is starting time, 10 end point, 2 is incrementation)

#List()- Without list(), function range() can not return value.



#for Loop

Used when you know how many times you want to repeat something.

#while Loop
