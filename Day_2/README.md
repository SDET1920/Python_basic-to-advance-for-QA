# Data Types

1. Data type means the type of value stored in a variable, and it's dynamically changed automatically. 


2. A data type defines the type of value a variable can store.

Example:

x = 10        # Integer
name = "QA"   # String
price = 10.5  # Float

Common Python data types: Given below will use these data type in code practice.

Integer (int)
Float (float)
String (str)
Boolean (bool)
List (list)
Tuple (tuple)
Dictionary (dict)
