#Numbers--

In Python, numbers are data types used to store numeric values. The main numeric types are:

1. Integer (int)

Output- <class 'int'>

2. Float (float)

Output-<class 'float'>

3. Complex (complex)- Numbers with a real and imaginary part.

Output- <class 'complex'>
